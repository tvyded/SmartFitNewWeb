# SmartFit — Платформа продуктивности, питания и умных тренировок

Современное полнофункциональное веб-приложение для тренировок с анализом техники движений в реальном времени на базе нейросети **MediaPipe Pose** (Python + OpenCV + WebSocket) и эргономичным интерфейсом на **React + TypeScript + Vite**.

---

## 🚀 Архитектура проекта

- **Frontend (Порт 3000)**:
  - React 19, TypeScript, Vite.
  - Управление тренировочным процессом: конструктор тренировок, конструктор собственного комплекса («Свой комплекс» с добавлением любых упражнений), таймер отдыха, журнал истории завершённых тренировок с детальной статистикой.
  - Верхняя шторка с калькулятором нормы калорий (Миффлин-Сан Жеор), дневником питания и профилем.
  - Стриминг кадров веб-камеры через WebSocket (`socket.io-client`) и отрисовка суставного скелета на Canvas.
  - Чистое сообщение об ошибке при отсутствии доступа к веб-камере (никаких фальшивых видео!).

- **AI Vision Backend (Порт 5000)**:
  - Python Flask + Flask-SocketIO.
  - `app/vision/detector.py`: декодирование кадров и инференс нейросети `mediapipe.solutions.pose`.
  - `app/vision/geometry.py`: точный тригонометрический расчёт суставных углов (`calculate_angle` через `np.arctan2`).
  - `app/vision/exercises/`: биомеханическая логика упражнений (`squat.py`, `shoulders.py`, `biceps.py`) с отслеживанием стадий движения (UP / DOWN), контролем углов коленей, локтей, корпуса и подсчётом чистых повторов.
  - `app/sockets/pose_socket.py`: двусторонний обмен событиями `process_frame` и `pose_feedback`.

## 🛠️ Запуск на локальном ПК (Windows / macOS / Linux)

### 1. Подготовка окружения
Убедитесь, что у вас установлены:
- **Node.js** (версия 18 или 20+)
- **Python** (версия 3.9, 3.10 или 3.11)

---

### 2. Запуск Python AI Vision сервера (Бэкенд)

Откройте первый терминал в папке проекта:

```bash
# Создание виртуального окружения (рекомендуется)
python -m venv venv

# Активация на Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# (или в классической командной строке cmd: .\venv\Scripts\activate.bat)
# На macOS/Linux: source venv/bin/activate

# Установка зависимостей компьютерного зрения
pip install -r requirements.txt

# Запуск сервера
python app.py
```
*Сервер запустится на `http://localhost:5000` и будет готов принимать видеопоток.*

---

### 3. Запуск веб-интерфейса (Фронтенд)

Откройте второй терминал в папке проекта:

```bash
# Установка зависимостей Node.js
npm install

# Запуск dev-сервера
npm run dev
```
*Приложение откроется по адресу `http://localhost:3000`.*

## ⚠️ Решение ошибки PowerShell: «npm.ps1 невозможно загрузить, так как выполнение сценариев отключено»

Если при вводе команды `npm run dev` в PowerShell появляется ошибка безопасности:
```text
npm : Невозможно загрузить файл C:\Program Files\nodejs\npm.ps1, так как выполнение сценариев отключено в этой системе.
+ FullyQualifiedErrorId : UnauthorizedAccess
```

### Решение 1 (Самое простое и быстрое):
Выполните команду в текущей сессии PowerShell:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```
После этого команда `npm run dev` сработает без ошибок.

### Решение 2 (Через cmd):
Вы можете запускать команду через стандартный командный интерпретатор:
```powershell
cmd /c npm run dev
```

### Решение 3 (Глобально для текущего пользователя):
```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```
Нажмите `Y` (Да) для подтверждения.

## 📋 Возможности приложения

1. **История тренировок**:
   - Нажмите на карточку «История тренировок» на главном экране.
   - Отображает подробную информацию по каждой сессии: название программы, дата и точное время завершения, длительность в минутах/секундах, общее число подходов и повторений, а также детальный список упражнений.

2. **Конструктор «Свой комплекс»**:
   - При выборе вкладки «Свой комплекс» список упражнений изначально пуст.
   - Вы добавляете только те упражнения, которые нужны вам (приседания, отжимания, планка, бицепс, плечи, выпады и т.д.), и настраиваете количество подходов и целевые повторения.

3. **Интеллектуальный контроль техники**:
   - При старте упражнения с AI-камерой приложение запрашивает доступ к веб-камере.
   - Никаких фоновых видеозаписей: если веб-камера не подключена или заблокирована браузером, отображается понятное уведомление с кнопкой повтора и возможностью пройти подход вручную.
   - Стриминг видеопотока на Python MediaPipe с моментальной отрисовкой суставных узлов и голосовыми/звуковыми эффектами.
