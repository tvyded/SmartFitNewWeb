# SmartFit — Платформа продуктивности, питания и умных тренировок

Современное веб-приложение на React + TypeScript + Vite, созданное на базе компьютерного зрения для анализа техники фитнес-упражнений в реальном времени.

## Основные модули и возможности

1. **AI-Тренер техники (Computer Vision & Pose Analysis)**:
   - Анализ позы в реальном времени через веб-камеру или встроенное демонстрационное видео.
   - Поддерживаемые упражнения:
     - 🦵 **Приседания**: контроль глубины (параллель 68°–105°), детекция слишком глубокого седа (< 65°) и недоседа.
     - 🤲 **Подъём на плечи**: угол разведения рук (75°–105°), контроль прямых локтей (> 155°) и высоты подъёма до уровня плеч.
     - 💪 **Сгибание на бицепс**: фиксация полного разгибания (>= 155°) и верхней точки (<= 42°).
   - Отрисовка скелета на Canvas в реальном времени с цветовой индикацией (зеленый / красный).
   - Звуковая обратная связь через Web Audio API (таймер обратного отсчета, чим успешного повтора, баззер ошибки, фанфары завершения подхода).
   - Сохранение истории подходов и подсчет общей статистики.

2. **Питание & КБЖУ**:
   - Персональный калькулятор по формуле **Миффлина-Сан Жеора** с учетом пола, возраста, веса, роста, коэффициента активности и цели (поддержание, похудение -15%, набор массы +15%).
   - Дневник питания за день с наглядными полосами прогресса калорий и макронутриентов (белки, жиры, углеводы).
   - Быстрое добавление типовых продуктов (куриная грудка, овсянка, яйца, рис, протеин, творог).
   - Применение рассчитанных норм прямо в дневник в один клик.

3. **Тренировочные программы**:
   - Комплексы **Full Body** и **HIIT Кардио** с интерактивными чеклистами.
   - Таймер отдыха между подходами (30 сек, 60 сек, 90 сек) со звуковым сигналом по завершении.

4. **Аутентификация & Профиль**:
   - Регистрация и вход пользователя с сохранением сессии и данных в локальном хранилище.

## Технологический стек

- **Frontend**: React 19, TypeScript, Vite
- **Vision**: MediaPipe Pose + расчет суставных углов на Canvas
- **Аудио**: Web Audio API (процедурный синтез без внешних файлов)
- **Стилизация**: Модульный CSS с анимациями (плавающие геометрические фигуры, кольца, частицы)
