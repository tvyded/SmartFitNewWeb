# Обновление главного экрана, истории тренировок и режима «Свой комплекс»

План реорганизации интерфейса главного экрана, создания полнофункционального экрана детальной истории тренировок с отображением времени, длительности и всех подходов, а также доработки конструктора для старта с пустого списка в режиме «Свой комплекс».

---

## Подтвержденные решения пользователя

> [!IMPORTANT]
> На основе ответов в интервью утверждены следующие проектные решения:
> - **Удаление 3 блоков популярных программ**: на главном экране под кнопкой «Начать тренировку» убираются 3 карточки пресетов. Вместо них размещается блок перехода в **«Историю тренировок»**.
> - **Отдельный экран истории тренировок**: история открывается на отдельном экране с карточками каждой сессии и интерактивным раскрытием деталей (аккордеон).
> - **Детализация каждой записи**: в каждой завершенной тренировке сохраняются и отображаются:
>   - Название программы (например, *Full Body*, *HIIT*, *Свой комплекс*).
>   - Дата и точное время завершения (например, *Сегодня в 17:45*).
>   - Длительность тренировки (например, *24 мин*).
>   - Развертываемый список выполненных упражнений с количеством подходов и повторов, а также отметкой *AI Камера*.
> - **Свой комплекс с чистого листа**: при переключении на «Свой комплекс» в конструкторе список упражнений изначально пуст (`[]`) — пользователь добавляет исключительно те упражнения, которые выбрал сам.

## 2. Структура данных и хранение

В модуль хранения `Storage` добавляется работа с полноценными сессиями тренировок:

```ts
export interface CompletedWorkoutSession {
  id: string;
  name: string;
  completedAt: string;          // ISO дата-время
  durationSeconds: number;       // Общая продолжительность в секундах
  totalSets: number;
  totalReps: number;
  exercises: {
    key: string;
    name: string;
    icon: string;
    hasAiCamera: boolean;
    setsCount: number;
    targetReps: number;
    unit: string;
  }[];
}
```

- Ключ хранения в `localStorage`: `smartfit_completed_sessions`.
- При завершении тренировки в `WorkoutRunner` формируется объект `CompletedWorkoutSession`, который автоматически сохраняется в историю.

## 3. Детализация компонентов

### А. Главный экран (`DashboardScreen.tsx`)
- Удаление 3 блоков пресетов внизу.
- Добавление карточки **«История тренировок»**:
  - Иконка 📜 / 🏆, название, общее число завершенных тренировок.
  - Дата и время последней тренировки (например, *«Последняя: сегодня в 14:20»*).
  - Стрелка перехода в экран истории.

### Б. Экран истории тренировок (`WorkoutHistoryScreen.tsx`)
- Верхняя панель с кнопкой «← Назад» и кнопкой очистки истории.
- Сводная плашка: всего тренировок, суммарное время активности, всего выполненных подходов.
- Список карточек тренировок:
  - Шапка карточки: название тренировки, дата (например, *22 октября 2026, 17:35*), бейдж длительности (*18 мин*), бейджи количества упражнений и подходов.
  - Кнопка «Показать упражнения ▼ / Скрыть ▲».
  - Развернутый список: каждое упражнение с иконкой, числом подходов, повторов и бейджем *👁️ AI Камера* (если использовалась камера).
- Состояние пустого списка (Empty State) с кнопкой быстрого перехода к созданию тренировки.

### В. Конструктор тренировки (`WorkoutBuilder.tsx`)
- При нажатии на вкладку **«Свой комплекс»**:
  - Список `exercises` очищается (`[]`).
  - Отображается подсказка: *«Ваш комплекс пуст. Нажмите «+ Добавить упражнение», чтобы включить нужные упражнения»*.
- При нажатии на пресеты *Full Body* или *HIIT* — загружаются соответствующие упражнения пресета.

### Г. Плеер тренировки (`WorkoutRunner.tsx`)
- Засекается время старта тренировки (`startTime = Date.now()`).
- При завершении тренировки вычисляется точная длительность в секундах и сохраняется полноценный объект `CompletedWorkoutSession`.
