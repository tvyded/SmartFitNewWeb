# Восстановление серверного ядра Python MediaPipe с новой React-оболочкой

План объединения оригинального Python-бэкенда (OpenCV, MediaPipe Pose, Flask-SocketIO) с новой функциональной React-оболочкой (главный экран, конструктор с чистым «Своим комплексом», таймер отдыха, история тренировок, верхняя шторка с питанием и профилем) и удалением демо-видео.

---

## Подтвержденные решения пользователя

> [!IMPORTANT]
> - **Возврат Python-сервера MediaPipe**: восстанавливаются все файлы архитектуры компьютерного зрения (`app/vision/`, `detector.py`, `geometry.py`, `exercises/squat.py`, `shoulders.py`, `biceps.py`, `app/sockets/pose_socket.py`, `app.py`, `requirements.txt`).
> - **Сохранение новой React-оболочки**: сохраняются все новые экраны и сценарии (главная страница со стартом тренировки, конструктор тренировок, выдвижная верхняя шторка с калькулятором и дневником, история тренировок).
> - **Удаление демо-видеозаглушек**: любые автовоспроизведения видео (`squat.mp4`, `shoulders.mp4`) при отсутствии камеры полностью удаляются.
> - **Обработка отсутствия веб-камеры**: если камера не подключена или пользователь отклонил разрешение в браузере, выводится информативное сообщение об ошибке с инструкцией предоставить доступ к веб-камере в настройках браузера.
> - **Связка React и Python WebSocket**: кадры с веб-камеры передаются клиентом по WebSocket в Python MediaPipe, где рассчитываются суставные углы, техника и повторения, а обратно на фронтенд приходят координаты скелета и статус.

## 2. Структура восстанавливаемых файлов Python

1. **`requirements.txt`**:
   - `flask`, `flask-cors`, `flask-socketio`, `python-socketio`, `mediapipe`, `opencv-python-headless`, `numpy`, `simple-websocket`.
2. **`app/vision/`**:
   - `base_exercise.py`: базовый класс упражнения (состояние, сброс, углы, повторения).
   - `detector.py`: класс `PoseDetector` на базе `mp.solutions.pose.Pose`.
   - `geometry.py`: расчет углов через `np.arctan2`.
   - `factory.py`: фабрика создания экземпляров упражнений по ключу (`squat`, `shoulders`, `biceps`).
   - `exercises/squat.py`: логика приседаний (глубина 68°–105°, ошибки, повторы).
   - `exercises/shoulders.py`: логика подъема на плечи (разведение 75°–105°, прямые локти).
   - `exercises/biceps.py`: логика сгибания на бицепс (полное разгибание >=155°, сгибание <=42°).
3. **`app/sockets/pose_socket.py`**:
   - Обработчики событий Socket.IO: `connect`, `select_exercise`, `process_frame`, `reset_exercise`, `finish_set`.
4. **`app.py`**:
   - Инициализация Flask приложения, CORS, Socket.IO сервера и раздача статики.

## 3. Обновление React-клиента

1. **Пакет `socket.io-client`**:
   - Установка `socket.io-client` для надежного обмена сообщениями с сервером по WebSocket.
2. **`WorkoutRunner.tsx` и `AiTrainerScreen.tsx`**:
   - Подключение к WebSocket при запуске упражнения с камерой.
   - Отправка кадров реальной веб-камеры с интервалом ~70 мс (14 кадров в секунду).
   - Прием `pose_feedback` и отрисовка скелета.
   - **Полное удаление видео-заглушек (`squat.mp4`, `shoulders.mp4`)**.
   - При ошибке веб-камеры (`NotAllowedError`, `NotFoundError`): отображение четкого предупреждения:
     *«Веб-камера недоступна. Пожалуйста, подключите камеру и разрешите доступ к ней в настройках браузера.»*
3. **Конфигурация запуска**:
   - Настройка скриптов для локального запуска на ПК: одновременный запуск бэкенда Python и клиента React, либо запуск бэкенда с проксированием в `vite.config.ts`.
   - Подробная инструкция в `README.md` для запуска на Windows/macOS.

## 4. План выполнения по шагам

1. **Восстановление Python-файлов**:
   - Создать `requirements.txt`.
   - Воссоздать модули `app/vision/` (`base_exercise.py`, `geometry.py`, `detector.py`, `factory.py`, `exercises/squat.py`, `exercises/shoulders.py`, `exercises/biceps.py`).
   - Воссоздать `app/sockets/pose_socket.py` и `app.py`.
2. **Интеграция Socket.IO в React**:
   - Установить `socket.io-client`.
   - Настроить прокси `/socket.io` в `vite.config.ts`.
3. **Обновление плеера тренировок и тренажера**:
   - Переключить захват кадров с веб-камеры на отправку через WebSocket в Python MediaPipe.
   - Удалить воспроизведение `mp4` видеофайлов при ошибке камеры.
   - Реализовать понятный интерфейс ошибки доступа к веб-камере.
4. **Сборка и валидация**:
   - Проверить компиляцию фронтенда через `compile_applet`.
   - Убедиться в корректности сокетов и перезапустить dev-сервер.
